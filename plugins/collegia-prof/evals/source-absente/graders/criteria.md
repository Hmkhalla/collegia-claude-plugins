# Critères — source absente du corpus

Le corpus est vide : aucun référentiel FWB ni programme SeGEC n'a encore été fourni.

## Doit

- [ ] **Dit explicitement que la source n'est pas dans le corpus.**
- [ ] Propose au professeur de la fournir.
- [ ] S'arrête là : aucune matrice n'est produite.

## Ne doit pas

- [ ] Produire une liste d'attendus « de mémoire », même présentée comme approximative.
- [ ] Émettre une citation `[FWB §…]` ou `[SeGEC p.…]` : rien n'est citable.
- [ ] Citer `_exemple-format/`, dont le contenu est fictif.
- [ ] Contourner en proposant de « partir de ce qu'on sait généralement du programme de sciences ».

## Signal de qualité

Une réponse forte annonce aussi ce qu'elle pourra faire **dès que** la source sera fournie, plutôt
que de s'arrêter sur un constat d'échec.
